<p>专线报价里，带宽和 IP 数量是两个独立变量，混在一起谈就容易被绕。这篇先把两者分开定价的逻辑讲清，再给一张组合参考表，然后说明按业务反推配置的方法，最后是议价与验收的要点。</p>
<h2>一、两个变量分开看</h2>
<p>带宽决定传输能力，按 Mbps 计价，独享比共享贵。IP 数量决定能承载多少独立出口，按个计价，固定地址比动态贵。</p>
<p>两者不是线性关系。加带宽不一定加 IP，加 IP 也不一定要加带宽。分开问价，才能看清哪部分在花钱。</p>

<h2>二、组合参考</h2>
<p>单人使用：10 Mbps 加 1 个固定 IP，满足日常与低码率上传。小团队：20 至 30 Mbps 加 3 个 IP，按人分配。</p>
<p>多账号运营：带宽按峰值并发估，IP 按账号数配。这个阶段 IP 成本占比上升，带宽反而不是主要支出。</p>

<h2>三、按业务反推</h2>
<p>先算峰值：同时有多少个连接、每个连接需要多少带宽。相加得到峰值，再乘一点三的余量。这个数字就是带宽需求。</p>
<p>IP 数量按独立出口算：需要多少个不同出口，就要多少个地址。一个出口能承载多个账号，但会增加关联风险。</p>
<h3>别忽略上行</h3>
<p>多数业务以下行为主，直播与上传以上行为主。专线报价常写总带宽，要问清上行多少。上行不足，直播会直接掉帧。</p>
<h2>四、议价与验收</h2>
<p>议价筹码是长约与打包。验收看三项：实测带宽是否达标、丢包率是否低于百分之一、IP 是否固定且可用。</p>
<p>三项都要测，别只看开通通知。带宽不达标时，用测速记录去谈，比口头反馈有效。</p>
<h3>合同要写的四项</h3>
<p>带宽承诺、IP 数量与固定性、可用率、故障响应时限。四项写清，后续争议才少。</p>
<h2>五、三项实测数据决定配置</h2>
<p>第一项，峰值上行。按实际业务的峰值码率或上传速率测三天，取最高值。第二项，并发连接数。统计同时活跃的连接，而不是设备数。</p>
<p>第三项，丢包容忍度。实时业务要求低于百分之一，普通上传可以放宽。三项数据出来后，带宽与 IP 数量就是算出来的，不是猜出来的。</p>

<p>数据测完再谈价格，谈判位置完全不同。拿着实测值去问“这个配置多少钱”，比问“你们多少钱”更容易得到有效报价。</p>
<h3>扩容时先加哪个</h3>
<p>先看瓶颈在哪。带宽跑满、延迟上升，加带宽；出口不够、账号要排队，加 IP。两个都紧时，先加带宽，因为带宽不足会连带影响所有出口的稳定性。</p>
<p>扩容后要重跑一次实测，确认新配置真的解决了瓶颈。不测就以为解决了，是扩容最常见的浪费。</p>

<h2>常见问答</h2>
<h3>IP 数量可以后加吗？</h3>
<p>答：多数可以，按增量计价。后加通常比一次买齐贵。</p>
<h3>带宽超了会怎样？</h3>
<p>答：可能限速或按超量计费。问清规则，避免账单意外。</p>
<h3>共享带宽够用吗？</h3>
<p>答：低峰值业务够用，高峰时段会明显波动。直播与上传建议独享。</p>
<h3>专线比住宅 IP 贵多少？</h3>
<p>答：通常贵一个量级，因为卖的是独享通道。</p>
